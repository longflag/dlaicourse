# 주식종목 발굴 프로그램 (Stock Discovery Program)

기술적 분석 지표를 활용하여 한국(KOSPI/KOSDAQ) 및 미국 주식 시장에서 매수/매도 유망 종목을 자동으로 발굴하는 프로그램입니다.

## 주요 기능

### 기술적 분석 지표
- **RSI** (Relative Strength Index): 과매수/과매도 판단
- **이동평균선** (MA5, MA20, MA60, MA120): 추세 판단
- **볼린저밴드**: 가격 밴드 이탈 감지
- **MACD**: 추세 전환 감지
- **스토캐스틱**: 모멘텀 반전 감지
- **거래량 분석**: 거래량 급증 감지

### 스크리닝 전략

**매수 신호:**
- 골든크로스 (MA20이 MA60 상향돌파)
- RSI 과매도 (RSI < 30)
- 거래량 급증 (20일 평균 대비 2배 이상)
- 볼린저밴드 하단 이탈
- MACD 골든크로스
- 상승 추세 (가격 > MA20 > MA60)
- 스토캐스틱 과매도 반전

**매도/주의 신호:**
- 데드크로스 (MA20이 MA60 하향돌파)
- RSI 과매수 (RSI > 70)
- 볼린저밴드 상단 돌파

# 규칙 기반 자동투자 시스템 (auto_invest.py)

`main.py`가 "종목 발굴(screener)"이라면, `auto_invest.py`는 **검증 → 집행**까지
담당하는 투자 시스템입니다. 감정 개입을 구조적으로 차단하는 것이 목적입니다.

## 투자 원칙

| 원칙 | 구현 |
|------|------|
| 규칙을 먼저 쓴다 | `strategy.py`에 규칙을 코드로 고정. 재량 판단 없음 |
| 규칙을 검증한다 | `backtest.py`로 과거 성과 검증. 통과 못하면 쓰지 않음 |
| 관찰 빈도를 낮춘다 | 월 1회 리밸런싱. 다음 실행일까지 시세를 보지 않음 |
| 리스크를 먼저 정한다 | `portfolio.py`의 비중 상한·역변동성 배분·서킷브레이커 |
| 기계적으로 집행한다 | 매매 지시서를 그대로 실행. 종목 가감 금지 |

## 내장 전략

| 전략 | 키 | 규칙 |
|------|-----|------|
| 듀얼모멘텀 | `dual_momentum` | 12-1개월 모멘텀 상위 N개 중 모멘텀 > 0 인 종목만 보유 |
| 추세추종 | `trend` | 200일 이평선 위 종목만 보유, 없으면 전액 현금 |
| 멀티팩터 | `multifactor` | 모멘텀·저변동성·하방안정성 합성 순위 상위 N개 |
| 저변동성 | `lowvol` | 변동성 하위 N개 (저변동성 이상현상) |
| 동일비중보유 | `buyhold` | 전 종목 동일비중 (벤치마크) |

## 사용법

```bash
# 1단계: 규칙 검증 — 전략별 과거 성과 비교
python auto_invest.py compare --market us --period 5y

# 2단계: 단일 전략 상세 분석 (연도별 수익률, 낙폭, 비용)
python auto_invest.py backtest --strategy dual_momentum --market us --max-dd 0.20

# 3단계: 이번 달 실행 지시서 — 무엇을 얼마나 살지
python auto_invest.py signal --strategy dual_momentum --market us --capital 10000000

# 4단계: 보유 종목과 대조한 매매 지시서
echo '{"AAPL": 10, "MSFT": 5}' > holdings.json
python auto_invest.py signal --strategy dual_momentum --holdings holdings.json
```

## 주요 옵션

| 옵션 | 기본값 | 설명 |
|------|--------|------|
| `--rebalance` | `M` | 리밸런싱 주기 (W/M/Q/Y). 길수록 비용·감정 개입 감소 |
| `--top-n` | `10` | 보유 종목 수 |
| `--weighting` | `inverse_vol` | 비중 방식 (`equal` / `inverse_vol`) |
| `--max-weight` | `0.20` | 종목당 최대 비중 (집중 위험 차단) |
| `--max-dd` | 없음 | 서킷브레이커 낙폭 한도 (예: `0.20` = -20% 도달 시 현금화) |
| `--cost` | `25` | 편도 거래비용 bps (수수료+세금+슬리피지) |

## 성과 지표 읽는 법

| 지표 | 의미 |
|------|------|
| **CAGR** | 연평균 복리 수익률 |
| **샤프지수** | 변동성 1단위당 초과수익. 1.0 이상이면 양호 |
| **최대낙폭(MDD)** | 고점 대비 최대 손실. *실제로 견딜 수 있는 수준인지가 핵심* |
| **칼마지수** | CAGR / MDD. 높을수록 "덜 아프게 번다" |
| **회전율** | 리밸런싱당 교체 비율. 높으면 거래비용이 수익을 잠식 |

## 미래참조(look-ahead) 방지 설계

백테스트가 현실보다 좋아 보이는 가장 흔한 원인은 미래 정보를 몰래 쓰는 것입니다.
이 엔진은 다음을 지킵니다.

- 신호는 **T일 종가까지의 데이터로만** 계산합니다.
- 체결은 **T+1일 종가**에 이루어집니다 (장 마감 후 실행 → 다음 날 주문).
- 재무·뉴스 데이터는 **백테스트에서 제외**합니다. 과거 시점 스냅샷을 구할 수 없어
  현재 값을 쓰면 미래참조가 되기 때문입니다.
- 거래비용을 회전율에 비례해 차감합니다.

## 설치

```bash
cd stock_discovery
pip install -r requirements.txt
```

## 사용법

```bash
# 전체 종목 분석 (한국 + 미국)
python main.py

# 한국 종목만 분석
python main.py --market kr

# 미국 종목만 분석
python main.py --market us

# 특정 종목 상세 분석
python main.py --ticker 005930.KS    # 삼성전자
python main.py --ticker AAPL          # Apple

# 매수 신호 종목만 필터링
python main.py --strategy buy

# 상위 10개 종목만 표시
python main.py --top 10

# 1년치 데이터 기반 분석
python main.py --period 1y
```

## 종합 점수 기준

- 기본 점수 50점에서 시작
- 매수 신호 하나당 +8점
- 매도 신호 하나당 -10점
- 이동평균 정배열 보너스 +10점
- RSI/MACD/거래량 등 추가 가감점
- 최종 점수 범위: 0~100점

## 주의사항

- 본 프로그램은 투자 참고용이며, 투자 판단의 책임은 본인에게 있습니다.
- 기술적 분석만으로는 완전한 투자 판단이 어렵습니다.
- 실시간 데이터가 아닌 일봉 기준 분석입니다.
