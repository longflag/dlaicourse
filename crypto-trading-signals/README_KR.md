# 암호화폐 종합 매매 시그널 분석기

BTC, ETH, XRP, SOL의 매수/매도 시점을 기술적 분석 기반으로 안내하는 프로그램입니다.

## 기능

### 분석 지표
- **이동평균선 (MA)**: 골든크로스/데드크로스 감지
- **RSI**: 과매수/과매도 판별
- **MACD**: 추세 전환 감지
- **볼린저 밴드**: 가격 위치 분석
- **스토캐스틱**: 모멘텀 분석
- **거래량 (OBV)**: 거래량 이상 감지

### 기간별 분석
- **단기** (30일): MA(5,10) 기반
- **중기** (90일): MA(20,50) 기반
- **장기** (365일): MA(50,200) 기반

### 외부 요인
- 글로벌 시가총액 변화율
- BTC 도미넌스
- 공포-탐욕 지수 (Fear & Greed Index)

## 설치 및 실행

```bash
cd crypto-trading-signals
pip install -r requirements.txt
python crypto_signals.py
```

## 면책 조항

이 프로그램은 교육 및 참고 목적으로만 제공됩니다. 투자 조언이 아니며, 실제 투자 결정은 본인의 판단과 책임하에 이루어져야 합니다.
